## 买之前先分清四个概念

这一步能帮你避开大部分买错的坑，每一个都直接影响你最后花多少钱。

**共享流量款和独享带宽款是两种产品。** 共享款按月流量计费，标的是峰值带宽，比如 200Mbps 峰值、1TB/月；独享款按配置速率计费，流量不限，比如 5Mbps 独享。间歇上传选共享看额度，7×24 持续传输选独享看速率，两条路的钱完全不一样。

**IX 系列需要云厂前置。** "上云互联优化专线"只能从阿里云、腾讯云、百度云、火山云、华为云、UCloud 等云厂 BGP 网络连入，也就是说你得先有一台云服务器做入口。它的月付便宜（158 元起），但算总成本时要把云前置的钱加上。

**流量是双向计费的。** 上行加下行一起算，计量型套餐流量用完会暂停，可以买流量重置或者提工单补差价升级。IX 系列的产品页直接标注"超量停机"，传大文件前先估好量。

**出口 IP 不接收入站。** 这类产品是给你在 VPS 里向外操作用的，不能拿来部署公开网站、跑支付回调或者对外提供服务。把它当成"跨境工作机"而不是"建站主机"，期望就对了。
